# Biblioteka workflow

Każdy workflow to osobny, ogólny SKILL.md do przeczytania i ewentualnej adaptacji; nie wymaga importu prywatnego workspace.

| Potrzeba | Procedura | Wynik |
|---|---|---|
| Wybór procesu | [Routing](../skills/workflow-routing/SKILL.md) | kryteria, ograniczenia, wybór |
| Dowód wykonania | [Weryfikacja](../skills/workflow-verification/SKILL.md) | wynik testu, zakres i blokery |
| Przekazanie kontekstu | [Handoff](../skills/workflow-handoff/SKILL.md) | zwięzły stan i następna akcja |
| Bezpieczny harmonogram | [Automatyzacja](../skills/workflow-automation/SKILL.md) | plan z limitem i zatrzymaniem |
| Praca równoległa | [Delegacja](../skills/workflow-delegation/SKILL.md) | osobne zakresy i przegląd |
| Porządek w plikach | [Higiena](../skills/workflow-hygiene/SKILL.md) | inwentarz i odwracalny plan |

Dodatkowa warstwa: po wykonaniu właściwego zadania zobacz [Step Beyond](https://github.com/aievolutionpl/step-beyond); sugestia rozszerzenia nie upoważnia do publikacji, wydatków ani innych skutków ubocznych.
