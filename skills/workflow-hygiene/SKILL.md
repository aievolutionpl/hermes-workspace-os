# workflow-hygiene

1. Sporządź inwentarz i wykryj istniejące zmiany; odróżnij źródła od wygenerowanych plików.
2. Zaproponuj czytelne nazwy i jedno kanoniczne miejsce; nie zakładaj, że duplikat jest zbędny.
3. Przed przenoszeniem lub usuwaniem uzgodnij zakres, utwórz backup i zaplanuj cofnięcie.
4. Sprawdź linki i ścieżki po zmianie; zgłoś nierozwiązane odwołania.
