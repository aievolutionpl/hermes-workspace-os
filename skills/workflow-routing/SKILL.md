# workflow-routing

1. Zapisz cel, zakres, ograniczenia i mierzalny wynik.
2. Sprawdź dostępne procedury i wybierz najmniejszą pasującą; nie zakładaj dostępności narzędzia.
3. Ustal wymagane dane i czy zadanie wymaga dostępu lub zgody.
4. Przy braku danych odnotuj blokadę; przekaż zadanie do weryfikacji.
