# workflow-verification

1. Przed pracą ustal mierzalne kryteria oraz dane testowe.
2. Uruchom test zachowania na faktycznym artefakcie; zapisz polecenie, wynik i zakres.
3. Dla zapisu zewnętrznego odczytaj dokładnie zmieniony obiekt. Nie utożsamiaj samego sukcesu API z potwierdzeniem efektu.
4. Zgłoś nieuruchomione testy i blokery; nie przedstawiaj hipotezy jako dowodu.
