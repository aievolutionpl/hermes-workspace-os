# workflow-automation

1. Określ źródło, cel, częstotliwość, strefę czasu, koszt i właściciela.
2. Zaprojektuj najpierw uruchomienie ręczne i tylko do odczytu; uwzględnij brak danych, deduplikację i retry.
3. Określ limit kosztu, alert, zatwierdzenie skutków ubocznych, sposób pauzy i cofnięcia.
4. Nie twórz harmonogramu ani nie publikuj bez upoważnienia. Po wdrożeniu sprawdź rzeczywisty przebieg i odbiorcę.
