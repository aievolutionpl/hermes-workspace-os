# Kontrole repozytorium

Uruchom z katalogu repo: `python3 -m unittest discover -s tests -v`.
Testy sprawdzają lokalne linki Markdown, zestaw modułów i skilli, strukturę frontmatter,
przykładowe szablony oraz wybrane wzorce prywatnych danych. Skan prywatności jest heurystyczny,
nie zastępuje ręcznego przeglądu ani skanera sekretów. Nie testuje aktywacji w Hermes ani zewnętrznych integracji.
